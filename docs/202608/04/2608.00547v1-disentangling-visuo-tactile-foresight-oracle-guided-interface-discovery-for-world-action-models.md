## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近基于触觉的世界动作模型联合建模了未来的视觉观察和触觉信号以指导动作生成，但如何为动作专家有效使用这些未来信息进行结构化仍未得到充分探索。直接使用学习到的世界动作模型研究这个问题是困难的，因为端到端行为将物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测以及难以解读的未来到动作接口纠缠在一起。为了使该接口可独立研究，我们引入了Oracle视觉-触觉预见（OVTF），这是一个受控框架，从模拟中验证的成功轨迹中提供配对的RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更清晰的问题：如果未来是成功的且物理上可执行的，哪种表示能让动作专家吸收其收益？在OVTF内，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注其自身的触觉流和相位对齐的未来视觉，同时阻止跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除了视觉到触觉的访问并独立处理每个未来模态。在UniVTAC模拟基准的七个任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这种受控比较表明，选择性相位对齐的视觉-触觉路由比完全模态隔离提供了更可操作的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

## 2. 方法论

### 2.1 OVTF：Oracle 未来源

- **来源**：从成功演示轨迹（HDF 文件）中采样配对的 RGB 视觉帧和左右触觉 RGB 帧，保证与当前初始化匹配、时间上有序、且在模拟中已验证成功。
- **相位定义**：设当前动作窗口参考索引为 \(\tau_{\text{ref}}\)，轨迹总帧数为 \(T\)，采样帧索引为 \(\tau_i\)，则归一化相位为：
  \[
  \phi_i = \frac{\tau_i - \tau_{\text{ref}}}{\max(1, T-1-\tau_{\text{ref}})} \in [0,1]
  \]
- **采样规则**：训练时，在 \([\tau_{\text{ref}}, T-1]\) 内均匀采样至多 100 帧；测试时，\(\tau_{\text{ref}} = \min(\lfloor p/2\rfloor, T-1)\)，其中 \(p\) 为策略调用序号。
- **不提供特权信息**：Oracle 不提供未来动作、未来关节位姿、物体位姿、模拟器状态或成功标签，仅提供视觉和触觉图像。

### 2.2 未来编码

- 未来视觉帧与触觉帧分别由可训练的 ResNet-18 编码（用 UniVTAC-ACT* 权重深拷贝初始化），输出序列：
  \[
  H, L, R \in \mathbb{R}^{N \times 512}
  \]
- 每个序列经过门控局部时间残差：
  \[
  X'_m = X_m + \tanh(g_m) \cdot \text{Conv}_{\text{DW}}(\text{LN}(X_m))
  \]
  其中 \(\text{Conv}_{\text{DW}}\) 为 depthwise Conv1d（kernel=5, padding=2, groups=512），门初始化为零。

### 2.3 AFM：非对称相位局部未来记忆

- 槽结构：12 个 512 维槽——4 个视觉槽、4 个左触觉槽、4 个右触觉槽。
- 相位锚点：\(C = \{0.125, 0.375, 0.625, 0.875\}\)。
- 注意力分数：结合内容注意力与高斯相位先验：
  \[
  \text{score}_{hk,i} = \frac{(q_h^k)^\top k_h^i}{\sqrt{64}} - \frac{(\phi_i - c_k)^2}{2 \times 0.18^2}
  \]
- 路由规则：
  - AFM：\(H \leftarrow H\)（视觉读视觉）；\(L \leftarrow (L, H)\)（左触觉读自身触觉流+视觉）；\(R \leftarrow (R, H)\)；禁止左右触觉互相读取。
  - IFM：\(H \leftarrow H, L \leftarrow L, R \leftarrow R\)，各模态完全独立。
- 每个触觉槽在一次联合注意力中同时处理自身触觉序列和视觉序列，而非先读触觉再读视觉。

### 2.4 ACT 集成与训练

- 当前观测（RGB、触觉、qpos）使用冻结的 UniVTAC-ACT* 编码器，未来槽乘以零初始化 tanh 门后与当前记忆拼接，一起作为 ACT encoder memory。
- ACT 解码器输出 50×8 的动作块，重叠块按权重 \(\exp(-0.01 \times \text{age})\) 聚合。
- 训练目标为掩码动作 L1 损失；禁用 CVAE，潜在 z 始终为零。
- 可训练参数：未来编码器、时间滤波器、槽注意力、ACT transformer、动作头；当前编码器冻结。

## 3. 实验设计

- **Benchmark**：UniVTAC 模拟基准（UniVTAC-ACT* 为基线）。
- **任务**：7 个接触丰富操作任务：
  - Put Shelf
  - Pull Out Key
  - Lift Bottle
  - Insert HDMI
  - Insert Hole
  - Insert Tube
  - Lift Can
- **数据划分**：
  - Put Shelf：episodes 0–39 训练，40–49 开发，50–99 评估；
  - Pull Out Key / Lift Bottle / Insert HDMI / Insert Hole：0–49 训练，50–99 评估；
  - Insert Tube / Lift Can：0–49 训练，50–99 评估（使用 head 和 wrist 相机）。
- **对比条件**：
  - **UniVTAC-ACT\***：无未来输入的基准策略。
  - **AFM Oracle**：训练与评估时都使用 Oracle 未来，采用 AFM 路由。
  - **IFM**：与 AFM Oracle 相同，仅将路由改为模态隔离（移除视觉→触觉访问）。
  - **AFM Forced-Zero**：使用 AFM Oracle 的 checkpoint，但在评估时将所有未来槽置零。
  - **AFM Zero-Train**：训练和评估时都不读取未来数据，未来模块输入为 12×512 零张量。
- **公平性保证**：同一任务内所有 AFM-family 条件使用完全相同的 episode 映射、评估器、预处理、归一化、时间聚合、滚动 horizon、early stopping、相机配置与成功判据，只允许 checkpoint 和未来信息条件不同。

## 6. 主要结论与发现

- **AFM Oracle 显著优于 IFM**：平均成功率 32.0% vs 23.7%，差距 8.3 个百分点，证明“相位对齐的视觉→触觉路由”比“完全模态隔离”更有利于动作专家吸收未来信息。
- **远优于无未来的基线**：UniVTAC-ACT* 为 14.9%，AFM Oracle 高出 17.1 个百分点。
- **未来信息确实被使用**：AFM Forced-Zero 降为 19.4%，说明训练中模型不是单纯依赖额外模型容量，而是实际使用测试时未来内容。
- **无未来时策略本身仍有效**：AFM Zero-Train 为 20.0%，仍高于基线 14.9%。
- **任务级差异**：
  - Put Shelf 和 Pull Out Key 从未来信息中获益最大；
  - Insert Tube 在 Oracle 与 Forced-Zero 下均为 42%，说明即使测试时切断未来也能保持较强性能；
  - Insert Hole 所有条件接近成功率下限，IFM 略高但无显著意义。
- **核心结论**：视觉-触觉预见的有用性不仅取决于未来预测是否正确，还取决于未来信息是否通过一个适合动作生成的接口被组织传递。

- **严格控制变量**：AFM vs IFM 只改变路由矩阵，其余完全相同，使结论干净可信。
- **丰富的对照条件**：Oracle/Forced-Zero/Zero-Train 三重消融，从多个角度验证了未来

- **丰富的对照条件**：Oracle/Forced-Zero/Zero-Train 三重消融，从多个角度验证了未来信息被实际使用，并进一步支持“接口设计决定胜负”的核心结论。
- **物理直觉驱动的接口设计**：AFM 的“视觉可引导触觉，触觉不引导视觉”是非对称路由，符合人类操作中视觉主导规划、触觉细腻反馈的直觉，使接口的可解释性较强。
- **工程实现规范**：时间相位归一化、门控残差、零初始化门等细节设计保证了训练稳定性，且所有条件共享预处理与超参，减少了实现偏差。

## 8. 缺点与局限性

- **对 Oracle 未来的依赖过重**：OVTF 使用已成功轨迹作为未来信息源，相当于实验环境中的“上帝视角”。真实应用中必须依赖一个可在线运行的视觉-触觉预测模型，而该模型的预测误差会在接口处被放大。论文未测试接口对预测噪声的鲁棒性，因此实际部署效果仍有gap。
- **动作专家单一**：仅集成 ACT 一种动作生成架构，未验证 AFM 接口在其他策略（如扩散策略、RVT 等）中是否同样有效。接口的通用性存疑。
- **统计力度不足**：每个条件仅一次训练、50 次 rollout，且无多次随机种子与置信区间。基线差距虽然明显（8.3 个百分点），但无法判断方差，个别任务（如 Insert Hole）结论难以分辨。
- **缺少与近期 WAM 方法的直接对比**：未与 VT-WAM、Tactile-WAM 等已经结合视觉与触觉的世界模型进行比较，无法判断 AFM 是否优于已有端到端接口设计，只能说明它优于给定消融变体。
- **只报告二值成功率**：没有记录力觉、局部接触事件、操作阶段时序等细粒度指标，无法揭示未来信息究竟改进了哪些具体行为。
- **训练曲线缺失**：所有模型在固定 2000 步后停止，未提供损失或成功率的收敛曲线，无法确认 2000 步是充分训练还是欠拟合，尤其对于多任务学习而言。
- **评估环境与任务分布受限**：仅在模拟基准下测试，未提及 sim-to-real 迁移；7 个任务中的一些任务成功率低至阈值附近，信息不足。
- **接口设计仍存在手工设定**：相位锚点数量、高斯宽度、槽数量均为固定超参，未做敏感性分析；若这些值受任务影响，则接口的可扩展性受限。

## 9. 综合评价与展望

该论文提出了一种新颖且严谨的评估范式（OVTF），将原本混杂在端到端多模态模型中的“未来预测质量”与“未来到动作接口”两个变量分离开来，并以此回答了“未来信息如何组织才能让动作专家受益”这一问题。实验设计充分体现了对变量控制的追求，三重消融和零训练对照为结论提供了坚实证据。然而，由于对 Oracle 未来信息的依赖、训练与评估规模有限、以及未引入更多基线和统计置信度，当前结论更多是“原理性验证”而非“工程最优方案”。未来工作可在该框架下引入真实预测网络、更丰富的动作专家体系、多随机种子评估及细粒度物理指标，以进一步验证接口设计的普适性与实用价值。
